# Dataset deliverable: IndicDLP subset used by IndicDoc AI

These CSV files describe exactly which pages and boxes this project used. They are generated by
`python scripts/export_dataset_csv.py` from the prepared data in `data/raw/indicdlp/` (built by
`scripts/prepare_indicdlp.py`).

**Source:** IndicDLP (Nath, Kukkala, Khapra, Sarvadevabhatla, ICDAR 2025),
[huggingface.co/datasets/ai4bharat/indicdlp](https://huggingface.co/datasets/ai4bharat/indicdlp), also listed on
AIKosh. MIT licence. Pages come from the official train / validation / test splits, so no test page was seen in
training by us or by the dataset authors.

| File | One row per | Columns |
|---|---|---|
| `pages.csv` | page (3,317) | split, file_name, language, domain, width, height, num_boxes |
| `boxes.csv` | labelled region (49,995) | split, file_name, class_id, class_name, x, y, width, height (pixels, top-left origin) |
| `class_counts.csv` | label (42) | class_id, class_name, train, val, test, total |
| `language_split.csv` | language (12) | language, train, val, test, total |
| `samples/` | language (12) | one real test page with its ground-truth boxes drawn |

| Split | Pages | Boxes |
|---|---|---|
| train | 2,293 | 33,667 |
| validation | 342 | 5,815 |
| test | 682 | 10,513 |

To rebuild the images themselves (2.3 GB, not stored in git), accept the dataset terms on Hugging Face and run
`python scripts/prepare_indicdlp.py`; the file names in `pages.csv` match its output.
